# Battery Channel Hub 使用说明

适用软件：电池测试通道预约与使用看板（Electron 桌面版）

文档日期：2026-09-03

本说明地址：`01-软件使用说明.md`

文件样式目录：`文件样式`
示例数据声明：本说明和全部附件只使用虚构示例数据，不包含真实申请、人员或设备信息。

## 1. 软件用途与边界

Battery Channel Hub 用于管理电池测试申请、子样品、设备通道、普通测试预约、正在测试样品、长期存储、退回申请、测试人员和操作日志。

软件中的通道状态、预约和使用记录是管理数据。本软件不直接连接或控制真实测试设备，也不会替代测试设备自身的安全联锁、工步设置和结果判定。开始真实测试前，操作人员仍须在设备端核对电池、通道、量程和安全条件。

正式 Electron 版使用本机 SQLite 保存业务数据。关闭窗口或重启电脑后，已保存的数据仍会保留。浏览器预览版仅用于界面查看，不能代替正式 Electron 版的数据持久化和文件导入导出能力。

## 2. 首次使用

1. 启动“电池测试通道预约与使用看板”。
2. 在登录页输入操作用户名并登录；软件当前没有密码或账号配置流程。
3. 登录后先进入“设备与通道”，核对设备、通道、量程和启停状态。
4. 进入“测试人员”，维护可选择的测试人员。
5. 进入“测试申请表格”，导入申请单，再安排普通测试或长期存储。

不要直接修改软件数据目录中的 SQLite、WAL 或 SHM 文件。需要转移或保存数据时，应使用 GUI 内的“备份数据”；需要恢复时，应使用 GUI 内的“恢复数据”。

## 3. 主界面导航

- **通道看板**：查看设备和通道的空闲、已预约、测试中等状态，以及当前项目和预计结束时间。
- **测试及时率**：按单个子样品统计计划开始时间与实际开始时间，选择日期范围并导出 PNG。
- **开始/预约测试**：从已导入申请中选择子样品，分配普通测试通道，可立即开始或预约。
- **正在测试样品**：查看当前普通测试，结束测试或提交退回申请。
- **长期存储样品**：登记长期存储，查看其状态，结束存储或提交退回申请。
- **已预约表单处理**：查看、调整和处理尚未开始的普通测试预约。
- **测试申请表格**：导入、查看、勾选和导出测试申请。
- **日志**：查看审计日志、通道使用记录及当前通道状态，并导出 Excel。
- **测试人员**：新增、编辑、启用或停用测试人员。
- **设备与通道**：维护设备、通道、量程和启停状态。

## 4. 导入测试申请单

### 4.1 支持的文件

GUI 支持导入 `.xlsx`、`.xls` 和 `.csv`。可以选择单个文件，也可以选择文件夹进行递归导入。选择文件夹时，软件会跳过以 `~$` 开头的 Excel 临时锁文件。

支持两种申请单布局：

1. **纵向字段样式**：第一列为字段名称，第二列为填写内容；一份文件通常表示一张申请单。
2. **横向申请汇总样式**：第一行为列名，此后每一行表示一张申请单。

旧版 `.xls` 使用方式和字段布局与附件中的横向 XLSX 样式相同。本文件夹已提供真实 Excel 97–2003（BIFF8）格式的 `.xls` 样例，不是仅修改扩展名的伪文件。

单个文件不得超过 25 MB；单个工作表不得超过 50,000 行。导入前建议确认申请单号、样品数量、项目、申请人、样品名称、测试类型及计划时间等关键字段。

### 4.2 导入步骤

1. 打开“测试申请表格”。
2. 选择“导入文件”或“导入文件夹”。
3. 在系统文件选择窗口中选择文件或文件夹。
4. 查看导入结果；无法识别、字段缺失或重复的数据会显示失败信息，不应忽略后继续安排。
5. 打开申请详情，核对申请单号、样品数量和自动生成的子样品。

### 4.3 批号和子样品编号规则

申请单号就是这一批电池的批号。若申请单中“样品数量”为 `N`，软件按三位序号生成 `N` 个子样品：

- `申请单号.001`
- `申请单号.002`
- ……
- `申请单号.NNN`

例如申请单号为 `APP-20260831-001`、样品数量为 3，生成的子样品为 `APP-20260831-001.001`、`APP-20260831-001.002`、`APP-20260831-001.003`。一块电池只对应一个子编号；一个通道同一时间只允许放置一块电池。同一次分配时，不得给两块电池选择同一通道。

## 5. 普通测试流程

### 5.1 预约或立即开始

1. 打开“开始/预约测试”。
2. 选择申请单，并勾选要测试的子样品。
3. 为每个子样品分别选择一个可用通道。
4. 填写计划开始、预计结束和必要备注。当前操作者取登录用户名；申请执行人员如需调整，应在“测试申请表格”中编辑。
5. 选择“预约”或“立即开始”，核对确认信息后提交。
6. 提交后到通道看板核对通道状态，并在申请详情中确认子样品状态。

若通道已被普通测试或普通预约占用，软件会阻止重复占用。填写预计结束时间时，该时间必须严格晚于开始时间；若提示时间无效，修正后可继续提交。通道停用、量程不匹配或数据冲突时，应先返回设备与通道页面核对，不要通过手工改数据库绕过限制。

### 5.2 已预约测试

打开“已预约表单处理”可查看尚未开始的预约。需要开始测试时，核对实际电池子编号、通道和测试人员后执行开始操作；需要退回申请时，使用页面提供的退回入口并填写原因。退回后，相关子样品和通道状态应同步释放或回到可重新处理的状态。

### 5.3 正在测试样品与退回

打开“正在测试样品”，可按记录查看申请单、子样品、通道、开始时间和预计结束时间。测试完成时执行“结束测试”；申请或安排需要撤回时执行“退回申请”，填写退回原因并确认。操作完成后应同时检查：

- 子样品不再显示为测试中；
- 对应通道不再被该记录占用；
- 申请单状态与剩余子样品一致；
- 日志中出现对应的成功或失败记录。

## 6. 长期存储流程

1. 打开“长期存储样品”。
2. 选择需要长期存储的子样品。
3. 填写预计结束时间；开始时间由软件在提交时记录，负责人取当前登录用户名，可补充备注。
4. 确认后开始长期存储。长期存储不选择、不预约也不占用测试通道。
5. 存储期间可查看状态、修改预计结束时间或备注，并处理异常。
6. 存储结束时执行“结束”；需要撤回到申请环节时执行“退回申请”并填写原因。

同一子样品不能同时处于普通测试/预约和有效的长期存储中。长期存储操作必须写入状态和审计，但不会写入或改变测试通道占用；结束或退回后，应检查子样品状态和日志，不需要释放通道。

## 7. 测试及时率

1. 打开“测试及时率”。
2. 选择开始日期和结束日期。
3. 查看测试及时率、可计算样品、及时开始、延迟开始和缺少计划时间。
4. 点击导出 PNG，选择保存位置。

统计单位是单个子样品。实际开始时间不晚于申请计划开始时间视为及时；只有日期而没有时分秒的计划时间按当日结束计算；缺少计划开始时间的样品单独计数，不进入及时率分母。导出文件名格式为 `测试及时率_<开始日期>_至_<结束日期>.png`。

## 8. 测试申请、日志和数据导出

### 8.1 申请导出

在“测试申请表格”中可导出：

- **申请汇总 XLSX**：包含“测试申请表格”和“测试项目明细”两个工作表；保留导入原始字段，并以 `原始_*`、`当前_*` 动态列区分原值与执行阶段修改值。
- **勾选申请 XLSX**：先勾选申请，再导出“选中申请表格”，列契约与申请汇总一致。

申请汇总导出使用页面上的开始日期和结束日期筛选当前“计划完成日期”；日期边界包含当天，日期留空的一侧不设边界，两侧都留空时导出全部申请。开始日期晚于结束日期或范围内没有申请时，软件会提示并且不生成空文件。导出后不要仅凭文件生成成功判断内容正确，应打开文件核对日期范围、申请数量、申请单号、样品数量和测试项目。

### 8.2 日志导出

在“日志”页面点击导出，可得到一个包含以下四个工作表的 XLSX：

1. `日志`
2. `使用记录`
3. `测试设备使用表2`
4. `通道当前状态`

其中日志是软件审计证据；使用记录和设备使用表用于追踪通道安排；通道当前状态是导出时的软件看板状态。软件记录不代表测试设备已经实际执行工步。

## 9. 数据备份与恢复

### 9.1 备份

1. 在 GUI 中选择“备份数据”。
2. 选择保存位置和文件名。
3. 默认保存为 `.batterydata`；也可以选择 `.json`。
4. 等待软件完成写入和校验，再将备份复制到受控位置保存。

`.batterydata` 和 `.json` 使用同一种带 SHA-256 校验的 JSON 备份结构，只是扩展名不同。备份包含本机业务状态，可能含人员、项目和测试安排，因此应按公司数据安全要求保管。

### 9.2 恢复

1. 恢复前先对当前数据再做一次备份。
2. 选择“恢复数据”，选取可信的 `.batterydata` 或 `.json` 文件。
3. 阅读恢复确认信息，确认目标确实是当前电脑和当前软件实例。
4. 恢复后重新打开申请、子样品、通道、正在测试、长期存储和日志页面逐项核对。

不要编辑备份包中的 `stateSha256` 或业务状态。任何内容被手工修改后，校验可能失败，软件应拒绝恢复。不要恢复来源不明的文件。

## 10. 设备、通道和测试人员维护

### 10.1 设备与通道

新增或编辑设备时，填写设备名称、厂家及必要说明；在设备下维护通道号、量程和启停状态。设备名称和通道标识应保持唯一、稳定。已有普通预约或普通测试占用时，不应停用或改变关键映射；应先结束或退回关联业务。长期存储不占用测试通道。

### 10.2 测试人员

在“测试人员”页面维护姓名和启停状态。停用表示不再用于新安排，不应删除或篡改既有历史记录中的人员信息。

## 11. 常见问题

### 11.1 导入后没有生成正确的子样品

先检查申请单号和样品数量。申请单号必须是稳定的批号，样品数量必须是 1–999 的整数。不要在 Excel 中把不同批次写成相同申请单号，也不要手工在申请单号中预先添加 `.001`；后缀由软件按数量生成。

### 11.2 无法选择某个通道

检查通道是否停用，是否已被普通预约或普通测试占用，以及同次分配中是否已经被另一块电池选择。长期存储不参与通道选择。若界面与实际不一致，先查看日志和通道当前状态，不要直接修改 SQLite。

### 11.3 导入文件无法识别

确认文件是真实的 `.xlsx`、`.xls` 或 `.csv`，而不是仅修改扩展名的文件；确认存在申请单号，纵向表有“字段/填写内容”结构，横向表第一行是列名。另检查文件大小和工作表行数限制。

### 11.4 恢复数据失败

确认文件是由本软件备份功能生成，内容没有被编辑，文件完整可读。校验失败时不要强制覆盖当前数据，应保留失败文件和当前备份用于排查。
